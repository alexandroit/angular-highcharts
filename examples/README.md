# Archived Examples

`angular-cli` and `webpack` preserve the original pre-Ivy example sources.
They are not maintained applications, are not installed by CI, and are not
published with `@stackline/angular-highcharts`.

Their dependency metadata is retained as `package.fixture.json` so the source
history remains inspectable without presenting unsupported development
toolchains as active repository dependencies. Use `docs-src/angular-22` for
the maintained browser application.
